--------------------------------------------------------------------------------
4. BROKEN OR FAILING APIS
--------------------------------------------------------------------------------
1. Forgot Password & OTP Delivery on Production:
   - forgot_password uses send_mail() configured with "django.core.mail.backends.console.EmailBackend". In production, OTP codes are logged to standard output, not delivered via SMTP/SMS. OTP login and reset will fail for real users.

2. Music File Upload & Storage Persistence:
   - upload_music saves files to local disk MEDIA_ROOT. On ephemeral or serverless containers (e.g. Render, Heroku), uploaded audio files disappear on container restart unless backed by S3/Cloud Storage.

3. Analytics Cache Key Invalidations & Multi-worker Sync:
   - get_user_cache_version uses cache.get_or_set. If Redis is absent or if LocMemCache is used across multiple Gunicorn processes, cache keys get out of sync, returning stale analytics.

4. Duplicate Preset Delete Endpoints:
   - /api/presets/<int:id>/ and /api/delete-preset/<int:id>/ map to separate functions delegating to delete_preset_record. Inconsistent API contract.


--------------------------------------------------------------------------------
5. ANDROID INTEGRATION RISKS
--------------------------------------------------------------------------------
1. JWT Authentication vs CSRF / Cookie Setup:
   - settings.py configures CSRF_COOKIE_SAMESITE = "None" and SessionMiddleware. Native Android apps use Authorization: Bearer <access_token> header. CSRF and session cookies are unnecessary for mobile and risk header confusion.

2. CORS Restrictions:
   - CORS_ALLOWED_ORIGINS lists web origins (localhost:3000, Vercel URLs). Native Android apps do not enforce CORS, but webviews or Metro bundler requests from local network IPs (e.g. 10.0.2.2 or 192.168.x.x) will be blocked.

3. Media URL Resolution on Android Emulator:
   - MusicTrackSerializer.get_audio_url uses request.build_absolute_uri(). If the host header resolves to localhost:8000, Android emulators (which require 10.0.2.2:8000) will fail to stream audio.

4. Background Timer & State Sync:
   - Android OS suspends background Javascript timers. ActiveSessionScreen client countdowns pause when app is backgrounded. Server resume_session computes paused_seconds correctly, but start_session lacks a persistent started_at timestamp in the database model.


--------------------------------------------------------------------------------
6. BOTTLENECKS
--------------------------------------------------------------------------------
1. Database N+1 Queries in Playlists:
   - PlaylistSerializer uses SerializerMethodField querying PlaylistTrack per playlist without prefetch_related('playlist_tracks__track'). Fetching 50 playlists triggers 51 SQL queries.

2. Redis Ephemeral Queue & Playback State:
   - Queue and playback state are stored exclusively in Redis (cache.set("music:queue:<user_id>", ...)). If Redis restarts or evicts keys under memory pressure, active user queue and playback position vanish permanently without database backup.

3. SQLite Default Database Configuration:
   - If DATABASE_URL environment variable is missing, fallback uses local SQLite (db.sqlite3). SQLite locks database files during concurrent writes from mobile clients.


--------------------------------------------------------------------------------
7. SECURITY REVIEW
--------------------------------------------------------------------------------
1. Hardcoded Secret Key Fallback:
   - settings.py includes a hardcoded development SECRET_KEY ('django-insecure-i&$deza...'). If SECRET_KEY is omitted in production environment variables, JWT signatures become publicly predictable.

2. DEBUG = True in Settings:
   - DEBUG is hardcoded to True on line 27 of settings.py. Production failures will leak Python tracebacks, database queries, and environment details to mobile devices.

3. Rate Limiting:
   - Properly configured: Login (5/min), OTP (3/min), Anon (100/day), User (1000/day).

4. Input Validation:
   - Uses Django password validators, integer range checks, and audio file extension validation (max 20MB).
